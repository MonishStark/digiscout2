## The Configuration

**Apache Configuration (httpd.conf):**

```
# Around line 478-482 in:
# C:\laragon-classic\bin\apache\httpd-2.4.54-win64-VS16\conf\httpd.conf

IncludeOptional "C:/laragon-classic/etc/apache2/alias/*.conf"
IncludeOptional "C:/laragon-classic/etc/apache2/sites-enabled/*.conf"  ← THIS LINE
Include "C:/laragon-classic/etc/apache2/httpd-ssl.conf"
Include "C:/laragon-classic/etc/apache2/mod_php.conf"
```

**What Changed:**

```diff
# .env.local
- LARAGON_APACHE_CONF_PATH=C:\laragon-classic\etc\apache2\conf.d
+ LARAGON_APACHE_CONF_PATH=C:\laragon-classic\etc\apache2\sites-enabled
```

## Vhost File Format

**Generated by laragon-apache-vhost-manager.ts (CORRECT):**

```
<VirtualHost *:80>
    ServerName business-name.test
    ServerAlias www.business-name.test

    DocumentRoot "C:/laragon-classic/www/wordpress-sites/sites/business-name"

    <Directory "C:/laragon-classic/www/wordpress-sites/sites/business-name">
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    <FilesMatch \.php$>
        SetHandler application/x-httpd-php
    </FilesMatch>

    ErrorLog "C:/laragon-classic/www/wordpress-sites/sites/business-name/error.log"
    CustomLog "C:/laragon-classic/www/wordpress-sites/sites/business-name/access.log" combined
</VirtualHost>
```

✅ No React rewrite rules
✅ Proper AllowOverride for WordPress .htaccess
✅ PHP handler configured
✅ Forward slashes in paths (Windows Apache requirement)
